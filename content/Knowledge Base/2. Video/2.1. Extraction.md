Task: Convert Format (mp4 ->  mp3)
```python
import ffmpeg # ffmpeg-python 패키지의 모듈임 # ffmpeg 패키지와 헷갈리지 말 것

input_video = 'sample.mp4'
output_audio = 'sample.mp3' 

# 오디오 스트림만 복사하거나 인코딩하여 추출
(
ffmpeg
.input(input_video)
.output(output_audio, acodec='libmp3lame', audio_bitrate='192k') # 파일명(및 확장자), 오디오 코덱, 음질(대규모 파일을 다루는 지식베이스 구축 시 음질을 낮춰 각 샘플의 용량을 줄이는 방안도 있다. 다만, 내 경우에는 STT용이므로 큰 상관은 없다)
.run()
)
```
